# 同人创作后续修改思路（2026-11-17 整理）

> 参考对象：炼字工坊「同人创作」（公测）的使用流程，2026-11-17 用免费账号实际点击走完前三步（开始创作需订阅，之后步骤未能体验）。只借鉴流程与交互思路，不复制其文案与代码。

## 一、参考产品的流程要点（我们自己的话概括）

1. **导航**：全局侧栏里「同人创作」一个入口；模块内用二级 tab：开始创作 / 原著世界 / 我的作品 / 同人广场。开始创作是一个三节点步骤条（选择原著 → 创作想法 → 确认设置），走完一步后在同一页纵向堆叠摘要 + 下一步内容，不分屏、不加内侧栏。
2. **第 1 步 选择原著**：站内原著库（按分类筛选 + 搜索），卡片展示资料条数、分类、剧情摘要、设定完整度；可选 1–10 部，第一部是主原著，其余为融合原著。上传原作是可选的附加入口。
3. **第 2 步 创作想法**：一排「方向」chip，点一下把带空位的结构化模板填进一个大文本框，空位都写明「可不填，AI 自动设计」；支持草稿自动保存、导入导出。方向里专门有「穿越空降」（新角色进入原著世界，从与核心人物产生联系开始改变剧情；填身份、能力、想接触的人物/剧情），以及多本穿越、反向穿越、重生、平行故事、剧情分叉等，各自带切入点字段（时间节点、地点、与主线的交点）。
4. **第 3 步 确认设置**：长篇规划（总章数、每卷章数→自动算分卷和总字数）；创作规则：原著遵循度三档（遵循 / 有据延展 / 分歧世界）、视角、章幅、模型。之后才「开始创作」。
5. **原著世界（资料库）**：一部原著拆成 世界设定 / 角色档案 / 剧情时间线 / 关系索引 四类档案；角色按势力分组，含多阶段人物状态（不同时期的实力/身份不同）。
6. **同人广场**：可阅读别人作品、基于某作品续写（我们暂不做社区）。

## 二、NovelOS 现状对比

| 环节 | 现状（v0.11.1/0.11.2） | 差距 |
|---|---|---|
| 原著资料 | 联网取材 / 粘贴 / TXT + 联网补充；18 个热门模板；卡片：人物/世界/势力/时间线/名场面 | 缺「关系索引」独立视图、人物多阶段状态 |
| 主角 | 只能从原著角色里选，原创角色要去设定库手动加 | **缺原创主角/穿越者流程（最优先）** |

| 立项流程 | 建同人书单页表单 | 改成三步步骤条，与侧栏子条目配合 |
| 多原著 | 已支持 crossover + extra_source_ids（≤9） | 主/融合原著区分要在界面上更直观 |
| 规模 | 完本模式已有字数档位 | 同人立项里直接设总章数/每卷章数 |

## 三、后续修改计划（按优先级）

### P0 原创主角（穿越者 / 本土原创 / 魂穿）
- 建同人书新增「主角来源」：原著角色 / 原创角色。原创下分三种：
  - 穿越者（现代人或其他世界的人进入原著世界，带不带记忆、知不知道剧情）；
  - 本土原创（原著世界土生土长的新角色，如与主角同村的发小）；
  - 魂穿某原著角色（身体是原著角色、灵魂是新人，OOC 检查要放宽到"身体身份"层面）。
- 原创角色卡字段：名字、身份/出身、来历方式、金手指/特殊能力（有上限和成长路线，不要重代价，符合原著力量体系）、性格与说话方式、想重点接触的原著人物、与原著人物的初始关系、**切入时间点**（从原著资料的时间线里选一个节点）。所有字段可不填，提供「AI 按原著设定生成」按钮（planner 角色，后台 Job）。
- 原创角色写进设定库，标记 `origin: oc`；OOC 检查跳过原创角色本人，但新增「世界规则一致性」检查：原创角色的能力、等级成长是否违背原著力量体系上限、是否与时间线冲突。
- 上下文：context_block 里加入原创主角卡 + 切入点前后的原著事件（只取摘要），让大纲和正文围绕"新角色改变剧情"展开。

### P1 立项改三步流程
- 侧栏「同人」子条目：联网取材 / 导入原著 / 原著资料 / 建同人书（v0.11.2 已做侧栏可展开）。
- 建同人书页内用步骤条：① 选原著（主原著 + 融合原著，卡片网格）② 创作想法（方向 chip → 带"可不填"空位的模板写入想法框，含主角来源与切入点）③ 确认设置（遵循度、视角、章幅、总章数/每卷章数→自动算卷数和总字数、是否完本模式）。
- 想法草稿自动保存到 localStorage，可重置。

### P2 原著资料增强
- 人物多阶段状态：每个人物可有若干阶段（时期 + 实力/身份/关系变化），切入点选定后上下文只取对应阶段，避免"开局就是封号斗罗"。
- 关系索引视图：从人物关系里汇总成可筛选的关系表。
- 角色按势力分组展示。

### P3 其他
- 方向模板补「多本穿越」「反向穿越（原著角色来现代）」「角色复活」「烂尾续写」等常见题材（用我们自己写的文案）。
- 模板库中的人物名和常见写法做一次联网核对（当前凭常识写）。
- 真实模型测试：挑 1 个模板跑联网取材 → 原创穿越主角 → 写 3 章，检查 OOC 与世界规则检查是否有效。

## 四、不做的事
- 不做原著资料付费解锁、社区广场、版权声明类提示（用户已明确不加申报/合规类文案）。
- 不复制参考产品的模板文案和任何原著原文。
