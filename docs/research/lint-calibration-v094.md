## 4. 本次改动

阈值全部集中到 `app/config.py`：`Settings.lint_profiles`（`PlatformLintProfile`，两套：`fanqie` 番茄档、`publish` 出版档），`Settings.lint_platform_map` 决定平台风格档用哪套（fanqie→番茄档；qidian、generic→出版档）。可用环境变量 `NOVELOS_LINT_PROFILES`（JSON）整体覆盖。原来散在 `humanlint.py`（弱化副词/主语单调/句长 CV/瀑布流短段字数）、`craft_zh.py`（强化词允许次数、口癖、口头禅、群众镜头）、`platform.py`（瀑布流段数、长段）里的常量改为从档位读；模块常量保留为函数默认值（兼容旧调用）。

| 阈值 | 番茄档 | 出版档 | 说明 |
|---|---|---|---|
| 长段字数 `long_para_chars` | **70 → 100** | 不查 | P95≈101 |
| 长段成片 `long_para_min_count` / `long_para_min_ratio` | **新增：≥3 段且占比 ≥10%** | — | 零星一两段长段是正常排版 |
| 长段定点修条数 `long_para_fix_max` | **5 → 3** | — | 只在成片时点名 |
| 瀑布流段数 `waterfall_run_max` | 8 | 4 | 未改 |
| 瀑布流短段字数 `waterfall_short_chars` | 30 | 30 | 未改（v0.8.3 已按样章调过） |
| 群众镜头 `crowd_shots_max` | 5 | 3 | 未改 |
| 强化词允许次数 | max(2, 字数×0.6/千) | 同 | 未改：ch1-user 的「死死×5、硬生生×3、一把×3」经人工审读确认是口癖 |
| 句末口癖 / 口头禅每章上限 | 2 / 2 | 2 / 2 | 未改：ch1-user「嘛×4、对吧×3」审读确认刷屏 |
| 弱化副词每千字 / 主语单调 / 句长 CV | 3.0 / 0.60 / 0.40 | 同 | 未改：样章均未触发 |
| LintThresholds 覆盖 | 短句占比 0.50、平均句长 9、对话占比上限 0.55 | 无 | 未改 |

注意：写作/语感重塑提示词里「番茄档每段不超过 70 字」是**写作目标**，lint 的 100 字是**报警线**，两者有意区分；语感重塑稿的段长校验（`polish_checks`）仍按 70 字提示。
