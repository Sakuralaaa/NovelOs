四组的定位（顺序固定，style 字段照抄前面的字母和名字）：
- A 番茄情绪爽感：书名用“身份反差 + 离谱金手指 + 逆袭爽点”，一眼看出主角赚了什么、谁要倒霉（参考句式：《让你[日常身份]，你把[离谱结果]？》《[开局处境]，我[反差爽点]》）。封面：高饱和暖色，主角正面半身特写，金光或神兵环绕。
- B 悬疑规则脑洞：书名立一条世界规则或一个生存悬念（参考句式：《我能看到[离奇信息]》《[场所]守则：[禁忌]》）。封面：暗色调，冷蓝与猩红光源，破碎时钟、规则纸条或一只眼睛。
- C 轻松沙雕：书名吐槽风、反套路（参考句式：《[反派]都哭了，你管这叫[辅助]？》）。封面：明亮漫画风，夸张的肢体和表情。
- D 起点正剧：四到六字的正剧名或意象名，像一部大世界长篇。封面：苍茫远景，云海孤峰或古城，水墨加金色烫印，人物占比很小。

要求：
1. 四个书名都要贴本书的真实设定（主角身份、金手指、开局困境），不能是换个题材也能用的空壳；四个书名彼此不能只差几个字。
2. subtitle 是放在书名下面的一句话钩子，不超过 20 个字。
3. hook 是简介第一句：两三句以内，写出开局困境和金手指第一次起作用的那一刻，要让人想点进去。
4. cover_prompt 是给生图模型的中文提示词，竖版 3:4，写清画面主体、色调、光源、构图，上方给书名留位置；不要在画面里写字。
