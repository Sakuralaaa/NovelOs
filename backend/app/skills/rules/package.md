# 包装规则

1. 书名候选 8 个左右，程序按四项打分（各 25 分）：长度 8–12 字；含数字；含情绪词；含身份或关系词。模型只负责提名。
2. 简介三段：一句钩子（处境 + 反常）→ 主线冲突与金手指（写清它强在哪）→ 一句悬念收尾。不剧透中点以后的反转。总长 150–300 字。
3. 标签 3–6 个，优先番茄分类里的现成标签（题材、人设、元素）。
4. 封面提示词只写画面，不写书名（书名由系统交给生图模型做成大字）：题材视觉母题 + 主角形象（只写外观，不写名字）+ 场景与光线 + 色调（高对比、亮部抓眼，番茄书架缩略图上也要醒目）+ 构图（竖版 3:4，上半部给书名大字留位置）+ 风格（厚涂/CG 写实/国风等）+ 书名字体建议（如金属浮雕、燃烧、碎裂、毛笔狂草，与题材呼应）。不要写「不要文字」。
5. 合规：发布到番茄时如实勾选 AI 申报；书名简介不得蹭真实名人或违规词。
