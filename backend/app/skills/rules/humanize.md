# 去 AI 味与描写增厚规则

## 原则
1. 一开始写对胜过事后改。事后改写只做定点修补：只改被点名的句子或段落，其余一字不动。
2. 清理以句内优化为主，保留全部有效信息：人名、数字、事件、因果一个都不能丢，不新增事实、不改情节走向。
3. 确定性 lint 放最后一轮复查，因为 LLM 改稿也会带来新口癖。

## 定点清理（patch）
- 翻案腔：无人主张时删掉否定侧，保留肯定侧（“那不是恐惧，是愤怒” → “那是愤怒”）。人物台词不改。
- 叙述破折号：右侧在解释、列举、揭晓的，改成逗号或拆成完整句；台词打断保留。
- 修饰副词：删动作前的微微、轻轻、缓缓、极轻、极慢（微微点头 → 点头）。
- 烂俗比喻与模板表情（嘴角勾起一抹、眼中闪过一丝、心中一凛、倒吸一口凉气）：换成具体动作，或者删掉。
- 翻译腔：当……时、对于……来说、这意味着、段首然而/此外/与此同时，改成顺口的中文语序。
- 情绪直述（一股莫名的情绪涌上心头）：改成看得见的动作、视线停留或身体受力；改不出来就删。

## 描写增厚（thicken）
只处理程序定位出来的段落：
- 裸对白段：给对白配上说话人的动作、神态或身边环境的变化（每段对白至少一半有配）；动作要符合人物卡的 habits / demeanor。
- 概述段：把“经过一番”“很快”“于是”“随后”带过的内容展开成一个小场面：谁、在哪、手上做什么、说了一句什么。
- 短句碎段：把同一主语的连续动作并成一句，长短交替。
- 不得新增人物、物品、设定或情节结果；段落数量与顺序不变；保持原有人称与视点。

## v0.2 新增清理项（程序 lint 会点名）
- 万能状语：“他笑了一下，带着一丝不易察觉的嘲讽” → 删掉状语留主句，或换成具体动作。
- 无情绪声线：“声音不大，却带着不容置疑的力量”“语气毫无波澜” → 直接写台词内容、声音特征或动作。
- 告知式心理：“他感到一丝失落”“显得有些兴奋” → 写外部可见的反应。
- 总结收束：“这一刻他终于明白”“反击才刚刚开始” → 删总结，收在动作或未解决的问题上。
- 模板通感与气场：“眼里淬了毒”“浑身散发着生人勿近的气息”“心里某个地方软了” → 写旁人的反应或一个具体动作。
- 弱化副词（缓缓、微微、轻轻、淡淡）每千字合计不超过 3 个；孤立自然的用法可保留。
- 主语单调：连续多句都以“他/她/人名”开头时，换成动作、物件或环境起句，或并成一句。
- 替换不复用：同一个词在一章里多次命中，每处给不同的具体写法；不要每次都换成“垂下眼”“顿了一下”，替换产物本身也会成为新口癖。
- 比喻先看功能再看密度：贴角色视角、能传递信息的单个比喻可以保留；抽象类（命运的齿轮）优先落回动作、物件、声音、后果。

## v0.6 手艺类定点修（程序逐句点名，只改这些句子）
- 重复强化词：死死、硬生生、一把（抓/掐/撕）、猛地、狠狠、重重、瞬间等，同一个词每章超过上限（默认 2 次，长章按每千字 0.6 次放宽）的部分删掉或换成具体受力与结果；几处替换不要用同一个词。
  - 例：「视线死死黏在那支笔上」→「视线黏在那支笔上」；「硬生生塞进夹缝」→「塞进夹缝，木屑跟着往下掉」。
- 陈词比喻：空气像灌了铅、像砂纸在磨、背脊像铁条、如坠冰窟、目光像刀子……换成现场才有的细节或删掉。
  - 例：「正堂里的空气像灌了铅」→「正堂里没人出声，油锅那边的滋啦声都听得见」。
- 量词搭配：只换量词（一柄铁砣 → 一块铁砣）。
- 口头禅/句末口癖（嘛、对吧、是吧、呗）超频：去掉多出来的那几处，用句式、语速、动作体现腔调。
- 群众反应镜头超过 3 个：删掉或并进主角视线里的一句，不新增人物。
