# 正文写作规则（场景化）

## 零、v0.6 六条硬规则（先于下面所有条目）
1. 状态账本说了算。每个场景开头的人物站位、朝向、手持物、衣着、伤势与义体状态，以程序给的“状态账本”为准。道具只能被写出来的动作移动；同一个物件前后外观一致；数字和角度前后一致。
   - 反例：反派一直攥着“硬壳烫金合同”，下一段主角“扫了一眼柜台上的合同，一把抓起那叠厚纸”。
   - 正例：反派把合同往柜台上一拍，硬壳磕出一声响；主角伸手按住合同封皮，把它从反派指下抽了出来。
2. 开篇三行见冲突（第 1–3 章）。前三段里冲突或异常已经发生；环境只附着在人物动作上，不单独占段。第 1 章必须让金手指/核心卖点露一次读者能感知的苗头（数字、提示、身体反应或一次小收益），一两句，不讲原理。
   - 反例：开头三段写天色、油烟、悬浮车，第四段反派才开口。
   - 正例：“叶老板，三十八万，今天签了吧。”韩铎把合同拍在门框上时，叶承手里的铲刀还卡在旧胶印里。
3. 主角每场至少一处简短内心。1–2 句判断、算计或情绪，夹在动作之间，让读者站进主角的脑子；不写超过 3 句的独白。
   - 正例：叶承没接笔。三千七百块，撑不了三个月，这人是算准了才来的。
4. 镜头给主角和对手。群众/配角反应镜头全章不超过 3 个；章末只留 1 个主钩，至多再加 1 个副钩，不要连抛三个悬念。
5. 口头禅和强化词按额度用。人物口头禅每章最多 1–2 次，腔调靠句式和用词；“死死、硬生生、一把、猛地、狠狠”这类强化词同一个词每章最多 2 次；不用“空气像灌了铅”“像砂纸在磨”“背脊像铁条”这类万能比喻。程序会在每个场景前告诉你剩余额度。
6. 意思不能写反。贬低就写“到顶了”，不写“没有上限”；称呼跟着关系走：叫“师父”就是已入门，“补录”的人还没入门；金属义体不会“发紫”，充血发紫的是接口周围的皮肉。

## 一、番茄开篇硬指标
1. 主角在前 300 字内出场，并且在做事，不是在发呆或回忆。
2. 前 500 字内出现冲突，前 1000 字内出现第一个钩子（危险、反常、悬念、打脸前奏之一）；第 1 章内金手指露面。
3. 每章结尾留钩子，钩子要落在动作、台词或决定上。
4. 前三章禁止：大段世界观说明、超过 200 字的内心独白、超过 300 字没有冲突的日常。
5. 打脸四拍：嘲讽 → 沉默 → 碾压 → 围观的反应。

## 二、不写概述，写场面
1. 正文不是细纲的扩写。禁止“经过一番周旋”“很快”“于是众人”“随后”这类一句话带过的概述；细纲里的每个节拍都要落成读者看得见的场面：谁在哪、手上在干什么、说了什么、对方怎么反应。
2. 信息靠动作、神态、环境、潜台词承载。人物不替作者解说设定，双方都知道的事不塞进对白。
3. 沉浸在视点角色身上：只写视点角色能看见、听见、摸到的东西。不凭空解说别人的心理（“像是在组织语言”“内心波澜起伏”），心理要有外部可观察的依据。
4. 人动景才出：环境随人物动作出现（推门才有风，掀帘才见光），不堆没人看的风景清单。
5. 感官密度随戏的分量走：关键转折写到受力、温度、阻力；过渡场景可以省，但要用连贯的叙述段落过渡，不能单句成段或一句对白带过。

## 三、对白
1. 每段对白至少一半配动作或神态（说话前后一句内有手、眼、身体或环境的具体动作）。
2. 禁止短句乒乓：不要连续 4 行以上的独行短对白；“嗯”“我知道”“然后呢”这类不推进局势的应答删掉，用具体动作推进。
3. 人物说话按人物卡：voice 决定句长与语气，catchphrases 偶尔出现（全章不超过 1–2 次），habits / demeanor 用在说话的间隙。隐去说话人名字后要能分辨是谁。
4. 对白标签默认用“说”，能从动作判断说话人就不加标签；不用“沉声道”“冷声道”“轻声道”“命令道”这类装饰标签。

## 四、句子
1. 句长长短交替：连续动作合成一个长句（主语只交代一次，逗号顺承），关键一击用短句。不要一句一段、每句都以“他/她”开头。
2. 删动作前的修饰副词：微微点头 → 点头，轻轻推开 → 推开，缓缓抬头 → 抬头。描写物理状态的保留（微微发烫的杯壁）。
3. 不写翻案腔：没人主张 A 时，不写“不是 A，而是 B”“没有 A，只有 B”，直接写 B。人物台词不受此限。
4. 叙述中不用破折号做解释、列举、揭晓结论，改成逗号或完整句；台词被打断、话没说完可以保留。
5. 比喻必须带真实的感官细节（材质、温度、重量、气味、形状），禁止烂俗比喻（一潭死水、受惊的小兽、溺水者抓住浮木）；同一段最多一个“像”。
6. 避开翻译腔：当……时、对于……来说、这意味着/这表明、段首的然而/此外/与此同时。
7. 少用“猛地”“骤然”和模板生理反应（喉结滚动、倒吸一口凉气、瞳孔骤缩、指节泛白），写身体实际的受力和停顿。
8. 不写点题升华和预告式套话（他不知道的是、这一切才刚刚开始、命运的齿轮）。
9. 叙述者不替人物数拍子（一下，两下，三下）。

## 五、连贯与章末
1. 本章第一个场景从“上一章结尾原文”接着写：位置、时间、伤势、手里的东西、情绪都要连上，不要重新开场或跳过上一章留下的悬念。
2. “人物与世界当前状态”是底账：已死亡的人只能以回忆、遗物或揭晓假死的方式出现；受了伤的人下一章还疼；丢了的东西不能凭空拿出来；角色只知道底账里他“已知信息”的内容。
3. 章末断在变化发生的那一刻：一个不可撤回的决定、一条改变解释的新发现、一次读者看得出的误判、或目标刚达成时冒出的更大对手、更大麻烦。禁止用“他终于明白”“这一切才刚刚开始”“他不知道的是”“无论如何他都会坚持下去”这类总结、升华、空泛预告收尾。
4. 爽点按“期待 → 压抑 → 释放”写：释放前要让读者等，释放后给围观反应或实际收获。

## 六、状态账本与变更声明
每个场景正文写完后另起一行写 `---STATE---`，给出本场景结束时的状态 JSON（cast：人物的位置、朝向、手持物、穿着、身体；props：道具在哪、在谁手里、什么样；env：光线、时间、车辆等会影响下一场的环境事实）。程序把它合并成账本交给下一个场景。

本章最后一个场景在状态 JSON 之后另起一行写 `---CHANGES---`，后面跟一个 JSON：
{"new_entities":[{"type":"character|item|location|faction|cheat|power|world","name":"","summary":""}],
 "state_changes":[{"entity":"名字","key":"状态项","value":"新值","visibility":"reader|author"}],
 "foreshadow":[{"action":"plant|advance|resolve","id":null,"desc":""}]}
没有就写空数组。生成结果是草稿，确认提交前不会进入事实底账。

state_changes 的 key 尽量用统一的键名，便于下一章核对：位置、处境、身体/伤势、境界/实力、持有物品、情绪、目标、已知信息、关系:对方名字、身份、生死。
全书级的变化（故事内时间、天气、局势）用 entity 写“全书”。角色得知秘密时登记“已知信息”，没登记的秘密下一章不能当作他已经知道。

## 七、网文节奏与爽感（v0.8.4，真实样章读后补充）
这一节优先于“感官密度”：文笔稳不等于有人看。番茄读者单手刷，没耐心。
1. 描写有预算：一章只有一两处“关键一下”（破境、出手、打脸、揭晓）值得写到受力和温度；其余过场一句带过。同一人物的受苦描写（流汗、青筋、咬牙、吐血、眼白发红）全章每种最多一次。
2. 主角要有态度：主角每章至少一次当面回应压力（一句噎人的话、一个让对方吃瘪的动作、一个当场兑现的判断），不能只是“心里记下了”。看出对手破绽，要么当场用，要么在本章结尾前用。
3. 主角有一句让人记住的台词：嘴硬、冷幽默、反讽或一句狠话都行，符合人物卡，不靠口头禅。
4. 收益要能比较：金手指或修炼的收获写成读者能比较的东西——读数、名次、对手的反应、做到了之前做不到的事；不写“一股暖流”“往上蹿了一截”这种看不出多少的话。
5. 不重复套路：本章结尾不能和上一章结尾是同一种画面（上一章结尾受伤倒地，这章就不能再以受伤倒地收尾）。
6. 期限、数字、地名这类“设定提醒”一章最多点两次，别每段都提“三十天后”。
7. 配角要有自己的理由：重要配角（尤其徒弟）第一次出场就要露出他非赢不可的具体原因（一个人、一笔债、一句被人说过的话），用一两句带出，不要大段回忆。
